实现要点

三个文件，零依赖，零构建。

Canvas 2D · 光轨流场

Perlin 噪声引导方向，双通道描边（宽幅辉光 + 高亮核心）叠加出长拖尾光轨，鼠标附近产生扰流涡旋。

CSS 动效 · 旋转光环

conic-gradient 沿 @property 注册的角度变量无限旋转，构成双层环绕光轨与流光描边；mix-blend-mode 叠加极光。

零依赖

没有框架、没有打包器，双击 index.html 即可在浏览器中运行。
