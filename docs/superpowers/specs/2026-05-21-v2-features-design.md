# 法考刷题助手 v2 功能设计

## 概述
在现有 v1 基础上增加：题目搜索、错题重做模式、扩充题库、新增科目、裁判文书参考。

## 一、题目搜索
- 搜索框位于标题下方、筛选栏上方
- 输入时 200ms 防抖实时搜索
- 弹出下拉面板显示匹配结果（科目标签 + 题目文字 + 关键词高亮）
- 点击结果跳转到该题，自动切换科目
- 无匹配显示"未找到相关题目"
- 点击外部或 Esc 关闭面板

## 二、错题重做模式
- 入口：筛选栏右侧"错题重做 (N题)"按钮
- 进入后仅从 localStorage 错题本抽取，随机顺序
- 答对自动移出错题本，答错保留
- 错题清空后显示完成提示
- 可随时退出返回正常刷题

## 三、新增科目 & 扩充题库
- 新增：刑诉法(~20题)、民诉法(~20题)、知识产权法(~15题)
- 扩充：民法(+10)、刑法(+10)、行政法(+10)
- 总计约 115 题

## 四、裁判文书参考
- questions.json 每道题可选 `reference` 字段
- 包含：案号、法院、日期、案情要点
- 在解析区下方以可折叠区块展示
- 数据注明参考自中国裁判文书网

## 五、数据格式
questions.json 保持现有格式，仅增加可选 reference 字段。
