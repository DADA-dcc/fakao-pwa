隐私政策

应用名称：法考刷题助手（Fakao）　·　生效日期：2026-11-15

本应用是一款面向法律职业资格考试（法考）备考的离线刷题练习工具。我们高度重视你的隐私，本政策说明应用如何处理你的信息。

一、我们收集哪些信息

  • 不收集你的姓名、手机号、身份证号、位置、通讯录、相册等个人身份信息。
  • 刷题记录、错题本、学习进度等，仅保存在你设备的本地存储（浏览器/应用本地存储），不上传服务器。
  • 应用支持离线使用，不需要登录账号即可使用核心功能。

二、权限说明

权限是否使用用途
网络访问仅加载页面与题库更新题库/打开页面
定位 / 通讯录 / 相机 / 麦克风不使用—
存储本地保存你的刷题进度（仅本机）

三、第三方与数据共享

  • 应用不接入第三方广告、统计、推送或其他数据采集 SDK。
  • 页面通过 GitHub Pages 托管，访问网页时的基础访问日志由托管服务方按通用规则处理，我们不获取、不存储这些日志。
  • 我们不向任何第三方出售或共享你的个人信息。

四、数据存储与删除

  • 刷题进度等数据仅存于本机；清除应用/浏览器数据或卸载应用即彻底删除。
  • 应用本身不保留可识别的服务器端个人数据。

五、儿童隐私

本应用面向备考法考的成年用户，不面向 13 周岁以下儿童，也不会主动收集儿童信息。

六、政策更新

如本政策发生变更，我们会在本页面更新并标注生效日期。

七、联系我们

对隐私政策有疑问，可通过项目主页反馈：github.com/DADA-dcc/fakao-pwa/issues
