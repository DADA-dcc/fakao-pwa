## 二、已确认的运行时报错

### 1. 开屏动效首帧崩溃（线上 + 本地均复现）

```
TypeError: Cannot read properties of undefined (reading 'id')
  at updateUIHeaderAndTimeline (cover.html:1241)
  at renderSceneFrame (cover.html:1295)
```

原因：`renderSceneFrame` 用 `now - lastFrameTime` 求 dt，首帧 `now` 可能小于初始化时的
`performance.now()`，dt 为负 → `masterTime` 变负 → `sceneIndex = -1` → `SCENE_META[-1]` 为 undefined。

修复：`cover.html` 中把 dt 夹紧到 `[0, 0.1]`，并在累加后保证 `masterTime >= 0`。

### 2. 考试倒计时显示错误

`('0' + 180).slice(-2)` 得到 `'80'`，180 分钟被显示成 `80:00`，且倒计时从 80 开始递减。

修复：新增 `formatClock()`（支持 `H:MM:SS`），`updateQuestionTimer`、`updateExamTimerDisplay`、
`formatTimer` 统一走该函数。现在显示 `2:59:58`。

### 3. 搜索框完全没有实现

HTML/CSS/变量都在，但没有任何事件监听，输入关键词无反应。

修复：补全索引搜索（题干 + 选项、高亮命中、点击跳转、Esc 关闭、空结果提示）。

### 4. 右上角按钮重叠

`#aiSettingsBtn` 固定在 `top:16px; right:20px`，遮住页头的主题/动效按钮，点击被拦截。

修复：移到左上角（移动端同步调整）。

### 重要发现：多选答案判定

此前 3262 道题的答案存成 `"A,C,D"`，而前端用 `chosen === q.answer` 与 `q.answer.split('')` 判定，
多选题**永远判错**。已在两处修复：

1. 载入时归一化：去除非 A–D 字符并排序（`A,C,D` → `ACD`）；
2. 判定处统一走 `normAnswer()`（单选、多选提交、考试评分、错题记录、解析渲染）。

验证：6/6 道逗号答案多选题点选正确字母后均显示「✔ 回答正确」。
